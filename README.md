# hukx 小作品集

hukx 的静态作品集首页：四个小游戏、三套表情包，再加一个小工具。

纯静态 HTML/CSS，无后端、无第三方库。手机优先。

## 本地预览

在本目录启动任意静态服务器，例如：

```bash
cd /workspace/games/hukx-lab
python3 -m http.server 8768
```

然后用手机或浏览器打开 `http://127.0.0.1:8768/`。

## 页面内容

- 小游戏：方仔摸鱼、煎饺合成、今日情绪抽签、软糖情侣默契测试，外链到已发布的页面，「开始玩」在新标签打开
- 表情包：方仔上班中、软糖双人、煎饺乐，均标注「微信表情包 · 即将投稿」
- 小工具：Model Router Studio
- 页脚：作者 hukx · [请作者喝奶茶](https://afdian.com/a/hukxai)
